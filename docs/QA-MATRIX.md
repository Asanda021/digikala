# فاز ۸: ماتریس پذیرش بازارنما

تاریخ تهیه: ۱۴ اکتبر ۲۰۲۶
این فهرست تفاوت بین «کدنویسی شده» و «آزمون واقعی قبول شده» را مشخص می‌کند.

## بررسی‌های خودکار
- [ ] اجرای bash scripts/verify.sh: تمام PHPها و JavaScriptها بدون خطای نحوی
- [ ] اجرای bash scripts/build-theme.sh: خروجی ZIP معتبر و SHA-256
- [ ] فایل ZIP حاوی پوشه bazarnama، فایل style.css و index.php
- [ ] اجرای smoke test در وردپرس آزمایشی با WP-CLI

## فروشگاه و رابط
- [ ] راه‌اندازی بدون خطا با WooCommerce فعال و غیرفعال
- [ ] بررسی فارسی، RTL، فونت‌ها، چسبیدگی‌ها و اعداد
- [ ] صفحه اصلی، مگامنوی واقعی، دسته‌ها، جست‌وجو، فوتر و بخش‌های شخصی‌سازی‌شده
- [ ] نمایش کالاهای ساده، متغیر، تخفیف‌دار و ناموجود
- [ ] عملکرد قیمت، موجودی، سبد و افزودن به سبد
- [ ] فیلترهای بازه قیمت، موجودی و تخفیف، جداگانه و ترکیبی
- [ ] جست‌وجوی AJAX با مقدار کوتاه، بلند و nonce نامعتبر
- [ ] مقایسه تا ۴ کالا و علاقه‌مندی تا ۴۰ کالا در همین مرورگر
- [ ] حذف/مخفی شدن محصول در API عمومی بلافاصله بعد از تغییر وضعیت انتشار
- [ ] فرم پیگیری با شماره سفارش درست و ایمیل اشتباه بدون افشای اطلاعات

## امنیت، عملکرد و دستگاه‌ها
- [ ] تست مرورگر در ۳۲۰، ۳۷۵، ۴۳۰، ۷۶۸، ۱۲۸۰ و ۱۴۴۰ پیکسل
- [ ] آزمون Tab، Enter و Escape و کنترل صفحه با کیبورد
- [ ] آزمون XSS، CSRF، خطای AJAX و اعتبارسنجی تمام ورودی‌ها
- [ ] بررسی سرعت، Core Web Vitals، خطاهای کنسول و منابع سایت
- [ ] کنترل HTTPS، عدم کش صفحات خصوصی و تداخل افزونه‌های سئو
- [ ] آزمون سبد و تسویه‌حساب کلاسیک و بلوکی WooCommerce
- [ ] آزمون روش‌های ارسال، مالیات، کد تخفیف و پرداخت آزمایشی موفق و ناموفق
