# گزارش آزمون اجراشده قالب بازارنما

تاریخ: ۱۴ اکتبر ۲۰۲۶
هدف: ثبت دقیق کنترل‌های انجام‌شده، محدودیت‌های آزمون و ایراد اصلاح‌شده.

## شواهد اجرا در محیط چت

**آزمون پویا با شبیه‌سازی DOM و localStorage روی کد واقعی JavaScript: ۹ سناریو پذیرفته شد.**

۱. باز شدن منوی موبایل با کلیک: PASS
۲. باز شدن پنل دسته‌بندی با کلیک: PASS
۳. بستن پنل دسته‌بندی با Escape: PASS
۴. بستن منوی موبایل با Escape: PASS
۵. جلوگیری از افزودن کالای پنجم به مقایسه: PASS
۶. حذف محصول از فهرست مقایسه: PASS
۷. افزودن پس از آزاد شدن جای خالی مقایسه: PASS
۸. جلوگیری از ذخیره کالای چهل‌ویکم در علاقه‌مندی: PASS
۹. غیرفعال بودن localStorage بدون استثنای غیرقابل‌کنترل و با هشدار قابل نمایش: PASS

**ممیزی ایستا:** ۲۱ فایل PHP، ۲ فایل JS و ۶ فایل CSS بررسی ساختاری شدند. فایل‌های اصلی، مسیر includeها، دارایی‌های استایل/اسکریپت، نبود تابع تکراری در دامنه قالب، کنترل nonce جست‌وجوی عمومی، کنترل وضعیت محصول، رهگیری رسمی ووکامرس و منع کش صفحه خرید مشاهده شدند. ۱۲ کنترل اولیه پذیرفته شد و یک ایراد پیوند Open Graph صفحه آرشیو پیدا شد.

**اصلاح ایراد:** نشانی اشتراک‌گذاری صفحه فروشگاه، دسته‌بندی محصولات، آرشیوها و فهرست نوشته‌ها با نشانی واقعی هر صفحه جایگزین شده است. بازبینی فایل اصلاحی: PASS.

**تجدید ساخت بسته:** `dist/bazarnama-1.4.0.zip` از ۳۰ فایل قالب ایجاد مجدد شد؛ ۳۰ CRC-32 و فهرست مرکزی ZIP کنترل شدند. نسخه جدید: ۱۳۶٬۵۴۰ بایت و blob `4b561fff9937ef140d0a2d030686bab56dfd8fd5`.

## آزمون‌هایی که هنوز اجرا نشده‌اند

- PHP lint واقعی با `php -l` روی تمام فایل‌های قالب. محیط محلی PHP نصب است اما دریافت مستقیم محتوای GitHub به آن به دلیل محدودیت شبکه انجام نشد. بررسی ساختاری جای lint نیست.
- نصب واقعی روی WordPress و WooCommerce در staging و بررسی Fatal/Warn در لاگ PHP.
- آزمون مرورگر و عکس صفحه، کنترل عملکرد RTL و موبایل در عرض‌های مقرر.
- افزودن به سبد برای محصول ساده/متغیر/ناموجود، کوپن، هزینه ارسال، مالیات و تطبیق ارقام.
- آزمون تسویه‌حساب کلاسیک و بلوکی با درگاه تست و کنترل وضعیت سفارش موفق/ناموفق.
- آزمون امنیت عملی AJAX، CSRF/XSS، محدودیت فراخوانی، حقوق دسترسی و نفوذپذیری افزونه‌ها.
- اسکن Core Web Vitals، سازگاری مرورگر و کش CDN.
